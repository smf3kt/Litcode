Alternative B replaces all dialog callbacks with the card transport and adds client-gated controls absent from the reviewed local source. The schema-derived QuestionHostResult discriminant is kind questions. P3's empty annotations map is preserved. The complete mapper retains AFK before followUp, before free response, before structured or cautionary answers. qht/L preserve reversible quoting; notes-only and Other steer the model to read the actual text. Source number steering accepts a finite decimal in min/max without imposing step divisibility.

sourceQuestionResults is a pinned compatibility choice. Fresh CLI and explicit reload default true. Authored and managed false retain priority. Original absent/false metadata keeps the prior indexed JSON and prior factory card JSON. The existing partialAnswers flag still owns admission and AFK deadline behavior. No duplicate editor, timer, permission owner or plan approval authority is introduced.

The tool validates image siblings and model-text budget before host publication. Existing queue cancellation prevents late callbacks from publishing results. ToolUseResult/StoredToolUseResult and Session's schema carry the complete variant. Live Agent delivery and retained child transcript projection preserve it. The child test uses a real child-mode Session/Agent with an explicitly supplied interaction callback; Registry/standalone-child callback availability is unchanged and is not claimed as a new interactive child host.

QuestionResultRows uses the existing native document renderer, platform marker and themed text primitives. questionResultLines ports Dh/Nh/jh predicates and supplies inline rows too. Source memo caches and $e/offscreen/gutter hooks are adapted to the existing document lifetime and padding. Global native renderer equivalence is not claimed.
