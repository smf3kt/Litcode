# W378 plugin hook load settlement

Status: independently VERIFIED_SCOPED. Base `dc51435`. Hooks remains Partial.

## Predicate

A failed plugin module load rejects its caller. Once that failure has settled and its declaration is removed, subsequent settlement waits can complete; a loaded module can continue to serve its own edit chain. Every still-running load remains included in the wait.

## Adaptation

The original `started` Promise remains the caller's outcome. A separate `Promise.allSettled(starts)` barrier waits for each load, including a slow sibling after an early failure, without keeping that failure as an ancestor of subsequent barriers. This adapts the source's removable wait lifetime; it does not port the worker/respawn state machine. Concurrent reconciliation, replacement and worker semantics remain separate. The `loadProjectConfig` call site discards `applyPluginHooks`'s returned Promise, so this package does not claim that all startup failures are caught. The recovered `a_e` [2385002,2389680) catches individual declaration and module load failures, logs them and continues its admission pass; its handling and the host call site's rejected-Promise behavior require a separate source-grounded startup package.
